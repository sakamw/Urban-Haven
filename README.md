# Urban Haven

Urban Haven is a lading page for apartments located in Murang'a, Kiharu.

![Urban Haven ](image.png)

## Getting Started

Fork this repository for those who wish to contribute and clone it to your local machine:

```bash
git clone https://github.com/sakamw/urban-haven.git
```

Navigate to the repository:

```bash
cd urban-haven
```

Install all the necessary dependancies:

```bash
npm install
```

Spin up the server:

```bash
npm run dev
```
